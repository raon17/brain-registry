What mastery should look like

You should consider a topic mastered when you can do all of the following without relying on step-by-step tutorials:

  • Explain the underlying concept
  • Explain why the method works
  • Implement the method in Python
  • Use the relevant library correctly
  • Interpret the output
  • Identify assumptions
  • Identify failure cases
  • Compare alternative methods
  • Apply the method to unfamiliar data
  • Communicate the result to a non-technical audience
